# Codex project guidance

Read `CODEX_HANDOFF.md` before changing this project. It records the active
branch, unfinished work, validation state, design intent, and the next task.

Preserve the existing dirty worktree. Do not discard or overwrite uncommitted
topic-view and navigation-transition changes. Keep Shop UI direct, restrained,
media-led, and native: top-level category changes move horizontally; content
drill-ins use shared-view zoom transitions.
